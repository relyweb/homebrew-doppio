# homebrew-doppio

Homebrew tap for [Doppio](https://github.com/relyweb/doppio) — a macOS menu-bar
app that keeps your Mac awake for agentic tasks (Claude Code, omp, opencode,
Codex, Gemini), even when locked or with the lid closed.

```sh
brew tap relyweb/doppio
brew install --cask doppio
```

The cask here points at release artifacts published in the main
[relyweb/doppio](https://github.com/relyweb/doppio) repository.
